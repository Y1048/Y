# 미사용 코드 정리 (2026-09-03)

## 범위

현재 실행 진입점과 소스 참조를 확인하여 미사용 파일 20개, 해당 파일 기준
4,450줄을 삭제했다. 설명은 [CODE_GUIDE.md](CODE_GUIDE.md)에 분리하고,
활성 Mink 코드에는 짧은 한국어 주석 세 곳만 추가했다.
파일 이름에 demo/prototype이 있다는 이유만으로 삭제하지 않았다.

G1 접속, 원격 파일 변경, 물리 명령 발행은 하지 않았다.
제어 계산, PD 게인, IK 가중치, 제한값, 하드웨어 승인 설정은 변경하지 않았다.

제거했다. 현재 충돌 제약과 안전 검사를 삭제하거나 통과 기준을 완화한 것이 아니다.
HOLD 검사는 현재 Gate 5 경로 및 `TEST_G1_GATE6_HOLD_OFFLINE.bat`를 사용한다.
현재 추적 문제 분석에는 저장된 캡처와 활성 FeasibleTargetPlanner 검사를 사용한다.

## 보존 항목

- `run_mink_g1_right_arm_prototype.py`: 활성 제어기의 공용 모듈이며 명시적 baseline 비교 경로다.
- `experimental_stateful_gate7_controller.py`: 저장된 캡처 재생에서 사용한다.
- TWIST2 원본과 최소 오른팔 파생 코드: 인덱스 비교 및 통합 근거로 필요하다.
- 현재 Gate 검사, Jog, 실측 표시, 카메라, 회귀 테스트와 물리 출력 프로필.
- Startup Recovery 및 사용자가 보류한 실험.
- Unity 직렬화 자산과 외부 SDK, 원본 참고 자료, 기록된 캡처와 로그.

정적 참조가 없다는 사실만으로 외부 도구나 Unity 자산을 미사용으로 판정하지 않았다.
따라서 이는 미사용이 확인된 코드의 정리이며, 남은 모든 파일이 항상 실행된다는 뜻은 아니다.

## 함께 수정한 사항

- 카메라 검사: 구형 DLS 데모를 불러오지 않고 현재 공용 모델과 Mink 초기 자세를 사용한다.
- 좌표계 검사: 실제 사용하는 공용 위치/회전 변환 함수를 검사한다.
- Mink cost 검사 3개 추가: 설치된 Mink의 Jacobian/error 가중, cost 배율, LM 항을 수치 검증한다.
- `START_MUJOCO_ONLY.bat`: 현재 파서에 없는 `--scene control --view overview` 옵션만 제거했다.
- 프로젝트/도구 README, 아키텍처, `CHAT_HANDOFF.md`의 진입점과 링크를 갱신했다.

## 검증

- 정리 전 backend: 258개 통과.
- 정리 후 backend: 기존 유지 테스트 204개와 새 Mink cost 테스트 3개, 총 207개 통과.
  줄어든 테스트는 삭제한 구형 구현 전용이며, 활성 경로의 제한 기준을 낮추지 않았다.
- hardware bridge: 168개 통과.
- 카메라 모델, 축, 렌더링, 전송 검사 통과.
- TWIST2 최소 변경 소스 비교 및 추출한 오른팔 7축 계산 검사 통과.
- 프로젝트 소스의 삭제 파일 참조 검사 통과.
- `config`의 JSON 15개는 정리 전후 SHA256이 동일하다.
- 삭제한 모듈에 해당하는 Python 캐시 18개도 제거했다.
- MuJoCo 단독 실행기의 현재 CLI 옵션 확인 및 수정 범위의 `git diff --check` 통과.

실제 Quest/Unity Play 및 G1 동작을 재시험하지 않았다.
기록된 IK의 국소 제한 정체 문제는 이번 정리로 해결했다고 볼 수 없다.
