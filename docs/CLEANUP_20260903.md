않는다. 재사용하지 않기로 결정하면 이 로컬 파일만 삭제하고 과거 결과는 보존한다.

`VIEW_G1_LIVE_MUJOCO.bat`는 계속 수신한 전신값 표시이므로 둘 다 보존한다.

효과 없는 표현식 두 줄만 제거했다. 20 tests / 3 subtests 통과.
파일 삭제/이동, 제어 코드 수정, G1/WSL/DDS 실행은 하지 않았다.

사용자가 아래 캐시 9폴더 삭제를 승인했다. 절대 경로와 reparse point 부재를
확인한 뒤 삭제를 요청했으나 실행 도구의 정책에 의해 명령 실행 전 차단됐다.
따라서 삭제 완료가 아니며, 우회 삭제는 시도하지 않았다.

이번 점검에서는 파일을 삭제하거나 이동하지 않았다. 아래는 현재 실행 참조와
