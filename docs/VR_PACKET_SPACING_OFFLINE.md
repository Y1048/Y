# VR 목표 속도 오프라인 재현 (2026-09-08)

G1/VR/UDP/DDS 없이 배포한 UpperTargetOffline 수정 헤더를 MSVC로 직접 실행했다.
test/study 프로그램만 실행했으며 로봇 제어 프로그램은 실행하지 않았다.

조건: 제어 tick50Hz, 속도0.7rad/s, 가속도10deg/s²=0.1745329252rad/s².
22번 관절을 -1rad에서 시작해 고정 목표까지 이동. 다른 관절은 고정.
패킷은50Hz,3틱마다(약16.7Hz),1/3/1/6/2/4틱 간격 반복(20~120ms) 세 종류.
각 조합20초를 계산했으며 정착은 위치오차<1e-5rad,속도<1e-4rad/s 기준이다.

| 목표 이동량 | 최고 목표 속도 | 정착 시간 |
|---|---:|---:|
| 0.05rad (2.9도) | 0.090912rad/s | 1.14초 |
| 0.2rad (11.5도) | 0.185005rad/s | 2.20초 |
| 1rad (57.3도) | 0.415388rad/s | 4.86초 |
| 3rad (171.9도) | 0.700000rad/s | 8.38초 |

세 패킷 스케줄의 고정 목표 결과는 동일했다. 12조합 모두 속도/가속도 상한,
고정 목표 초과방지,다른28관절 유지,신선도 상실 후 갱신 중단/재시작 금지 통과.
기존 방향전환·pinch 해제·원천 입력 age 소진 시험도 재실행해 통과했다.
3rad는 속도 상한 도달을 확인하기 위한 소프트웨어 시험값이며 물리 실행 제안이 아니다.

이 결과는 C++ 목표 제한기만 검증한다. Mink의 동적 목표,실제 네트워크,하체 정책,
writer 제한기 및 모터 추종은 포함하지 않는다. 고정 목표의 패킷 간격 독립성이
시간에 따라 바뀌는 목표의 결과까지 동일함을 뜻하지 않는다.
수정 후 실제 G1 로그는 연결이 끊겨 회수하지 못했으므로 실측 개선은 아직 미확인이다.
